## 🔁 How I learn

1.  **Understand** the concept and why it is needed.
2.  **Implement** it in a focused example.
3.  **Test** normal and failure cases.
4.  **Debug** errors and understand their causes.
5.  **Refactor** toward cleaner, maintainable code.
6.  **Document** what I learned and revisit weak areas.

## 🔐 Security principles

-   Never commit `.env` files, database credentials, JWT secrets,
    private API keys, or real user tokens.
-   Keep secrets out of Git and use environment variables for
    configuration.
-   Validate incoming data and handle errors safely.
-   Use authentication, authorization, and secure cookie settings
    appropriately.
-   Test both successful requests and unauthorized or invalid requests.
